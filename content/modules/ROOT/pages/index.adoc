= Build a LAMP Development Container

Your LAMP application works on your laptop. Now get it to production.

Development needs speed - edit code, see changes instantly. Production needs stability - immutable, reproducible deploys.

This lab shows the development workflow. Lab 2 shows production packaging. Same app, different strategies.

*Time: ~30 minutes | Difficulty: Intermediate*

== What You'll Build

A database-backed LAMP application with:
- MariaDB database
- Apache web server
- PHP application that queries the database

You'll use volume mounts for rapid iteration - edit files on your host, changes appear instantly in the container.

== Why This Lab

Most Image Mode labs focus on platform engineering - building OS images with monitoring tools and compliance baselines. This lab focuses on application development - packaging a database-backed web application from development to production.

You'll write actual application code (SQL, PHP, Apache configs), not just install OS packages.

== What You'll Learn

- Authenticating to Red Hat's container registry
- Building containers with systemd support (for running services)
- Using volume mounts for fast development iteration
- Creating database schemas and seed data
- Writing PHP applications with database connectivity
- Configuring Apache for your application
- Understanding mutable workflows (dev) vs immutable (production)

== Prerequisites

- Basic container knowledge
- Familiarity with LAMP stack concepts
- Red Hat account (free at https://developers.redhat.com)

== Lab Flow

**Module 1:** Authenticate to the registry, build a base LAMP container

**Module 2:** Add your application (database, PHP code, Apache config)

**Module 3:** Test and iterate with instant updates
