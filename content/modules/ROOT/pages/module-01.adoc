= Authenticate and Prepare Environment

Most Image Mode labs focus on platform engineering - building OS images with monitoring tools and compliance baselines. This lab focuses on application development - packaging a database-backed LAMP application from development to production.

You'll start by authenticating to Red Hat's container registry to pull base images, then build a development container for your LAMP application.

*Time: ~8 minutes*

== Authenticate to Red Hat Container Registry

Pull RHEL base images from Red Hat's registry:

[source,bash,role=execute]
----
podman login registry.redhat.io
----

When prompted, enter your Red Hat account credentials.

[NOTE]
====
If you don't have a Red Hat account, create one at https://developers.redhat.com (free).
====

Verify authentication by pulling the base image:

[source,bash,role=execute]
----
podman pull registry.redhat.io/ubi10/ubi-init
----

You'll see layers downloading. This base image includes systemd support, which lets you run services (MariaDB, Apache) inside containers just like on a regular RHEL host.

== Create the Development Workspace

Set up your application directory:

[source,bash,role=execute]
----
mkdir -p ~/lamp-dev/app
cd ~/lamp-dev
----

This workspace will hold:
- `Containerfile` - defines your LAMP container
- `app/` - your application files (SQL, PHP, Apache config)

Unlike OS-focused Image Mode labs where you install monitoring tools, you're building an actual application. The `app/` directory will contain code you write, not just configuration.

== Review the Development Containerfile

A Containerfile is already provided. Review it:

[source,bash,role=execute]
----
cat ~/lamp-dev/Containerfile
----

*Expected output:*

[source,dockerfile]
----
FROM registry.redhat.io/ubi10/ubi-init

# Install LAMP stack
RUN dnf install -y mariadb-server httpd php php-mysqlnd && dnf clean all

# Enable services
RUN systemctl enable mariadb httpd

# Expose web port
EXPOSE 80

CMD ["/usr/sbin/init"]
----

This does three things:
1. Starts from a RHEL base image with systemd support
2. Installs MariaDB, Apache, and PHP
3. Enables services to start when the container boots

Notice what's *not* here - no application files. You'll add those using volume mounts (next module).

== Build the Development Container

Build the container image:

[source,bash,role=execute]
----
podman build -t lamp-dev .
----

You'll see installation steps as packages are installed. This takes ~2 minutes.

Once complete, verify the image exists:

[source,bash,role=execute]
----
podman images lamp-dev
----

*Expected output:*

----
REPOSITORY          TAG         IMAGE ID      CREATED         SIZE
localhost/lamp-dev  latest      a1b2c3d4e5f6  2 minutes ago   850 MB
----

You now have a base LAMP container. Next module: add your application and start the services.
